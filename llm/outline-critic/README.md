# Outline critic

The outline critic (kit: plan/workflows/drafting/prompts/outline-critic.md; the kit names no model, so Sonnet) asks where a chapter outline contradicts its notes, sheets, cards and rulings, or gives a beat no cause. [outline.md](outline.md) is 00400's outline with five faults: Agnes counting aloud, Agnes explaining the forty against the settled beat above it, the causeway bare an hour, Dell's cart arriving on cue, and Wren working the tide out before the crossing. Paste [run.md](run.md) into a fresh Sonnet session in the repo's top folder; never show it [answers.md](answers.md).

Score a run: `python3 llm/score.py llm/outline-critic/answers.md runs/outline-critic/report.md`
