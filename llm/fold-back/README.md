# Fold-back

The fold-back (kit: plan/workflows/drafting/prompts/fold-back.md; the kit names no model, so Sonnet) brings a chapter's outline and notes up to its draft and writes the Next pass list. The setup in [run.md](run.md) copies book/ to runs/fold-back/book/ with [prose.md](prose.md) and [notes.md](notes.md) in place of 00400's: the prose moves Agnes to the window (a choice the batch kept, [paper.md](paper.md), to be folded), puts the weed on the second post (drift against a settled line, never folded), drops the settled apron wipe (a beat item), keeps a line the batch held (a held item), and answers the notes' one open item. Paste the block into a fresh Sonnet session in the repo's top folder; never show it [answers.md](answers.md). [score.py](score.py) runs the key's thirteen checks, the Next pass quotes through the kit's tools/quotes.py; the untouched copy passes 4 of 13 and a hand-made fold-back passes all 13.

Score a run: `python3 llm/fold-back/score.py`
