# Procedures critic

The procedures critic (kit: plan/workflows/drafting/prompts/procedures.md, Sonnet) walks every carded process on the page step by step and flags a step skipped, misordered or done by the wrong hand. The four plants in [chapter.md](chapter.md) test the lens cleaned while still warm, a tide reading without its "and forty", a ring gone back over, and the bull's-eye started without fresh water. The book has no lens card, so [the-lens.md](the-lens.md) is the smallest invented card for it, written to agree with the unfaulted chapter. It reads the chapter, that card, book/world/things/the-tide-table.md, book/world/people/agnes-rook.md, book/world/places/the-causeway.md and book/world/things/the-log-book.md, by the index filled into the prompt. The book keeps no volume digest, so the third-showing check is not tested. Paste [run.md](run.md) into a fresh Sonnet session in the repo's top folder; never show it [answers.md](answers.md).

Score a run: `python3 llm/score.py llm/procedures/answers.md runs/procedures/report.md`.
